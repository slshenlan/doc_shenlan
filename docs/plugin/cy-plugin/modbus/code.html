业务封装说明 ​

  • 点位与指令由业务层 config 管理；
  • 连接、队列、心跳、事件、错误处理由 cy-plugin-modbus 提供。

注意事项 ​

  • 业务侧统一从 config，避免逐个导出。
  • 写入使用 params.values: number[]；
    • 线圈用 send(cmd, { action: 'on' | 'off' })；
    • 寄存器用 send(cmd, { values: number[] })。
  • 写指令数量以 values.length 为准，不是 params.range。未传 values 时会写成 [0]（仅 1 个点）。
  • CyModbusService.send 入队，返回 void。结果走事件；handleResult 需在 QUEUE_TASK_SUCCESS 里自行调用：extraData.handleResult(result)。
  • 未连接或无法格式化时，send 先触发 onFail，再派发 QUEUE_TASK_FAILED，再 throw cyModbusError。可用 cyModbusIsError 避免 catch 里重复处理。
  • connect 返回 Promise：失败先 onFail 再抛错。disconnect 清理失败只回调、不抛。
  • 需要全局唯一实例时，由业务自行持有 CyModbusService。
  • 点位地址放在 code/modules/{real,mock}.ts，业务字段（on/off 等）放在 methods 的 points。
  • 事件：modbus.on(cyModbusEvents.xxx)。
    • on 返回取消函数，离开页面必须 off 或调用返回值。
  • 队列串行发送；任务失败不重试，派发 QUEUE_TASK_FAILED，并停止心跳。
  • LOG_POINT_CODES 经 logPointCodes 传入插件：空数组打印全部参数/成功日志；填入起始地址后仅打印白名单点位（失败日志仍全量，心跳失败除外）。

/**
 * Modbus 指令参数
 */
export interface ISerialPortCommandParams {
  /** 起始地址 */
  start: number;
  /** 读取/写入范围 */
  range: number;
  /** 写入值（统一数组） */
  values?: number[] | null;
  /** 心跳间隔（毫秒） */
  duration?: number;
}

/**
 * 串口指令配置
 * - 必填：desc / method / type / params.start
 * - handleResult 等可缺省，由 createCommand 补齐
 */
export interface ISerialPortParamsConfig {
  /** 描述 */
  desc: string;

  /** 指令标识，用于回调路由 */
  method: string;

  /** Modbus 功能码类型 */
  type: cyModbusOptionType;

  /** 调用参数 */
  params: ISerialPortCommandParams;

  /** 响应数据转换（插件事件里仍带原始数组，业务自行调用） */
  handleResult: (val: number[]) => number[];

  /** 写入前参数转换 */
  handleParams?: (val: number[]) => number[];

  /** 按下/on 参数转换 */
  handleParamsOn?: () => number[];

  /** 抬起/off 参数转换 */
  handleParamsOff?: () => number[];
}

import type { ISerialPortParamsConfig } from "../types";

/**
 * 基于 ISerialPortParamsConfig 创建完整指令配置
 *
 * @param options - 指令声明（契约字段 + 可选 on/off）
 * @returns 完整 ISerialPortParamsConfig
 */
export function createCommand(
  options: Omit<ISerialPortParamsConfig, "handleResult" | "params"> & {
    params: Partial<ISerialPortParamsConfig["params"]> &
      Pick<ISerialPortParamsConfig["params"], "start">;
    handleResult?: (val: number[]) => number[];
  }
): ISerialPortParamsConfig {
  const {
    desc,
    method,
    type,
    params,
    handleParams,
    handleParamsOn,
    handleParamsOff,
    handleResult,
  } = options;

  const config: ISerialPortParamsConfig = {
    desc,
    method,
    type,
    params: {
      start: params.start,
      range: params.range ?? 1,
      values: params.values ?? null,
      ...(params.duration !== undefined ? { duration: params.duration } : {}),
    },
    handleParams: handleParams ?? ((val: number[]) => [...val]),
    handleParamsOn: handleParamsOn ?? (() => [1]),
    handleParamsOff: handleParamsOff ?? (() => [0]),
    handleResult: handleResult ?? ((val: number[]) => [...val]),
  };

  return config;
}

构造参数（IModbusServiceOptions）：

字段默认说明
debugfalse服务 / 串口调试日志
queueDebugfalse队列入队、剩余任务数
timeout800默认通信超时（毫秒）
slave1（cyModbusDefaultSlave）从机地址
connect{ baudRate: 9600, parity: 'odd' }可被 connect(options) 覆盖；还可传 dataBits / stopBits / bufferSize / flowControl
heartbeat.enabledfalse是否启用心跳
heartbeat.commandnull心跳指令（需带 params.duration）
logPointCodes[]任务日志点位白名单
eventBus内置 EventBus可注入自定义总线
onConnect空函数连接成功（同时派发 CONNECTED）
onFail空函数connect / send 失败

实例方法：

方法说明
connect(options?)Promise<void>，可选覆盖波特率等
disconnect(error?)停心跳、清空队列、关串口，派发 DISCONNECTED
send(config, options?)入队；options.action / options.values
configure(partial)运行时改 debug / timeout / slave / connect / heartbeat / logPointCodes
setHeartBeatConfig(command | null)更新心跳指令
setTimeout(ms)默认超时，须 > 0
isConnected()是否已连接
connectionStatus{ val, isConnected }，val 见 cyModbusConnectStatus
on / off订阅事件，on 返回 unsubscribe
getFunctionCodeText(code)功能码中文

错误 ​

connect、以及未连接或无法格式化时的 send：先 onFail，再 throw cyModbusError。

ts
try {
  await modbus.connect();
  modbus.send(holdingRegister.commands.getTestPass);
  modbus.send(coil.commands.batchTestingStart, { action: "on" });
} catch (error) {
  if (cyModbusIsError(error)) {
    return;
  }
  console.error(error);
}

队列 ​

  • 多次 send 进入同一串行队列，前一条结束（成功或失败）再执行下一条。
  • 失败不重试，派发 QUEUE_TASK_FAILED 并停止心跳。
  • disconnect 会清空队列。
  • 批量测队列时连续 send 互不相同的指令（不同 method / 功能码）：

CySerialPort ​

ts
import { CySerialPort, cyModbusOptionType } from "cy-plugin-modbus";

const port = new CySerialPort({
  debug: true,
  timeout: 1000,
  onFail: (err) => console.error(err.code, err.message),
});

await port.connect({ baudRate: 9600, parity: "odd" });
const result = await port.send(
  {
    slave: 1,
    function_code: cyModbusOptionType.READ_HOLDING_REGISTERS,
    starting_address: 0,
    quantity_of_x: 10,
    output_value: [],
  },
  { timeout: 1500 }
);
