cy-plugin-modbus ​

  • CyModbusService：指令配置、串行队列、心跳、事件。业务侧优先用这一层。
  • CySerialPort：单帧收发，不含队列、心跳、指令配置。

运行环境需支持 Web Serial API（Chromium 系浏览器，HTTPS 或 localhost）。

安装 ​

bash
npm install cy-plugin-modbus
1

快速开始 ​

ts
import {
  CyModbusService,
  cyModbusCreateCommand,
  cyModbusOptionType,
  cyModbusEvents,
  cyModbusError,
} from "cy-plugin-modbus";

const demo1 = cyModbusCreateCommand({
  desc: "读取 保持寄存器",
  method: "holdingRegisterGetTest",
  type: cyModbusOptionType.READ_HOLDING_REGISTERS,
  params: { start: 0, range: 1 },
});

const demo2 = cyModbusCreateCommand({
  desc: "写 单个线圈",
  method: "coilBatchTestingStart",
  type: cyModbusOptionType.WRITE_SINGLE_COIL,
  params: { start: 0, range: 1 },
  handleParamsOn: () => [1],
  handleParamsOff: () => [0],
});

const modbus = new CyModbusService({
  debug: true,
  queueDebug: false,
  timeout: 800,
  slave: 1,
  connect: {
    baudRate: 9600,
    parity: "odd",
    dataBits: 8,
    stopBits: 1,
    bufferSize: 255,
    flowControl: "none",
  },
  heartbeat: {
    enabled: false,
    command: null,
  },
  logPointCodes: [],
  onConnect: () => {
    console.log("onConnect");
  },
  onFail: (err) => console.error(err.code, err.message),
});

const onConnected = () => {
  console.log("已连接");
};
const onTaskSuccess = ({ result, extraData }) => {
  // result 为原始 number[]；换算请自行 extraData.handleResult(result)
  console.log(extraData.method, result);
};
const onTaskFailed = ({ error, extraData }) => {
  console.error(extraData?.method, error);
};

const offConnected = modbus.on(cyModbusEvents.CONNECTED, onConnected);
modbus.on(cyModbusEvents.QUEUE_TASK_SUCCESS, onTaskSuccess);
modbus.on(cyModbusEvents.QUEUE_TASK_FAILED, onTaskFailed);

try {
  await modbus.connect();
  modbus.send(demo1);
  modbus.send(demo2, { action: "on" });
} catch (error) {
  if (error instanceof cyModbusError) {
    console.error(error.code, error.message);
  }
}

offConnected();
modbus.off(cyModbusEvents.QUEUE_TASK_SUCCESS, onTaskSuccess);
modbus.off(cyModbusEvents.QUEUE_TASK_FAILED, onTaskFailed);

发送 ​

send 入队后返回 void。同一时刻只执行一帧，结果走事件，失败不重试。

ts
modbus.send(getTestPass);
modbus.send(batchTestingStart, { action: "on" });
modbus.send(writeSpeed, { values: [100] });
1
2
3
场景行为
未连接 / 参数无法格式化先 onFail，再派发 QUEUE_TASK_FAILED，再 throw cyModbusError
队列中发送失败不重试，派发 QUEUE_TASK_FAILED，继续下一条；业务失败不停心跳

options 见 发送选项。

队列 ​

  • 多次 send 进入同一串行队列，前一条结束（成功或失败）再执行下一条。
  • 失败不重试，派发 QUEUE_TASK_FAILED。业务指令失败不会停止心跳。
  • disconnect 清空尚未执行的队列。
ts
modbus.send(input.commands.getSensorOrigin);
modbus.send(holdingRegister.commands.getTestPass);
modbus.send(coil.commands.batchTestingStart, { action: "on" });

心跳 ​

默认关闭，用于探活。按 command.params.duration（毫秒）轮询。

  • 已连接且 enabled 为 true、并配置了 command 时自动启动。
  • 业务指令失败不会停心跳。
  • disconnect 或连接失败会清定时器，不改 enabled。关闭前 enabled 仍为 true 时，下次 connect 成功会再开。
  • stopHeartbeat() 会把 enabled 设为 false。之后 connect 不会自动再开，除非再次 startHeartbeat() 或 configure({ heartbeat: { enabled: true } })。
ts
const heartBeat = cyModbusCreateCommand({
  desc: "心跳",
  method: "heartBeat",
  type: cyModbusOptionType.READ_HOLDING_REGISTERS,
  params: { start: 0, range: 1, duration: 1000 },
});

const modbus = new CyModbusService({
  heartbeat: { enabled: false, command: heartBeat },
});

await modbus.connect();

modbus.startHeartbeat();
modbus.stopHeartbeat();

modbus.configure({ heartbeat: { enabled: true, command: heartBeat } });
modbus.setHeartBeatConfig(heartBeat);

事件 ​

默认事件名前缀 modbus:*。构造时可传入自定义 eventBus（实现 IEventBus，或使用导出的 EventBus）。on 返回取消函数，与 off 等价。

常量事件名payload
CONNECTEDmodbus:connected无
FAILEDmodbus:failed无
DISCONNECTEDmodbus:disconnected无
QUEUE_TASK_SUCCESSmodbus:queue:task:success任务成功
QUEUE_TASK_FAILEDmodbus:queue:task:failed任务失败
ts
import { EventBus, cyModbusEvents } from "cy-plugin-modbus";

const eventBus = new EventBus();
const modbus = new CyModbusService({ eventBus });

const off = modbus.on(cyModbusEvents.CONNECTED, () => {});
off();

实例方法 ​

分类方法说明
连接connect(options?)Promise<void>。options 覆盖默认串口参数，见 串口连接
连接disconnect(error?)停心跳定时器、清空队列、关串口，派发 DISCONNECTED
连接isConnected()是否已连接
连接connectionStatus{ val, isConnected }，val 见 连接状态
发送send(config, options?)入队。options 为 action / values
配置configure(partial)运行时更新 debug、queueDebug、timeout、slave、connect、heartbeat、logPointCodes。connect / heartbeat 浅合并
配置timeout / setTimeout(ms)默认通信超时。ms 须 > 0
心跳startHeartbeat()打开开关。已连接且已有 command 时立即发一拍并按 duration 轮询；未连接则等下次 connect 成功
心跳stopHeartbeat()关闭开关并清定时器
心跳setHeartBeatConfig(command | null)更新心跳指令；传 null 清除
事件on / off订阅事件。on 返回取消函数
事件eventBus当前事件总线
其它getFunctionCodeText(code)功能码中文，如「读保持寄存器」

连接状态 cyModbusConnectStatus ​

connectionStatus 为 { val, isConnected }。展示文案和样式由业务映射。

常量值说明
DISCONNECTED-1未连接
CONNECTED0已连接
FAILED1连接失败
CLOSED2主动断开

功能码 cyModbusOptionType ​

用于 cyModbusCreateCommand({ type })，以及底层 function_code。

枚举值说明服务层 send
READ_COILS1读线圈，点位 0 / 1params.range 为个数
READ_DISCRETE_INPUTS2读离散输入（只读）同上
READ_HOLDING_REGISTERS3读保持寄存器，16 位同上
READ_INPUT_REGISTERS4读输入寄存器（只读）同上
WRITE_SINGLE_COIL5写单个线圈{ action: "on" | "off" }
WRITE_SINGLE_REGISTER6写单个保持寄存器{ values: [n] }
WRITE_MULTIPLE_COILS15写多个线圈{ values: [0 | 1, ...] }，数量为数组长度
WRITE_MULTIPLE_REGISTERS16写多个保持寄存器{ values: [n, ...] }，数量为数组长度

读操作的数量取 params.range。写操作的数量取写入数组长度；未传 values 时按 [0] 写 1 个点。

错误约定 ​

场景行为
connect / send先 onFail(IModbusErrorInfo)，再 throw cyModbusError
disconnect 清理失败仅 onFail，不抛出
已是 cyModbusError直接 rethrow，避免重复回调
ts
import { cyModbusError, cyModbusIsError } from "cy-plugin-modbus";

if (cyModbusIsError(error)) {
  console.error(error.code, error.message, error.detail);
}

字段说明 ​

服务构造 IModbusServiceOptions ​

全部可选。未传时使用下表默认值。cyModbusDefaultSlave 为 1。

字段类型默认说明
debugbooleanfalse服务 / 串口调试日志
queueDebugbooleanfalse队列入队、剩余任务数
timeoutnumber800默认通信超时（毫秒）
slavenumber1从机地址
connectPartial<ISerialOptions>{ baudRate: 9600, parity: "odd" }默认串口参数，可被 connect(options) 覆盖
heartbeatIModbusHeartbeatOptions{ enabled: false, command: null }心跳，默认关闭
logPointCodesreadonly number[][]任务日志点位白名单。空数组：参数/成功日志全打。填入起始地址后只打白名单。失败日志仍全量（心跳失败除外）
eventBusIEventBus内置 EventBus自定义事件总线
onConnect(data: unknown) => void空函数连接成功。同时派发 CONNECTED
onFail(error: IModbusErrorInfo) => void空函数connect / send 失败

configure(partial) 可更新 debug、queueDebug、timeout、slave、logPointCodes，以及 connect、heartbeat 的部分字段（浅合并）。不能通过 configure 更换 eventBus、onConnect、onFail。

串口连接 ISerialOptions ​

CyModbusService 的 connect 与 CySerialPort.connect 共用。服务层调用 connect(options) 时，传入字段覆盖构造时的默认值。

字段类型必填默认说明
baudRatenumber是服务层默认 9600波特率，常见 9600、115200
parity"none" | "even" | "odd"是服务层默认 "odd"校验位
dataBitsnumber否8数据位，7 或 8
stopBitsnumber否1停止位，1 或 2
bufferSizenumber否-读写缓冲区（字节），须小于 16MB
flowControl"none" | "hardware" | "software"否-流量控制

底层 CySerialPort.connect 不带服务层默认值，调用时必须传入 baudRate 和 parity。

心跳配置 IModbusHeartbeatOptions ​

字段类型默认说明
enabledbooleanfalse是否启用心跳
commandIModbusCommandConfig | nullnull心跳指令，需带 params.duration

指令配置 IModbusCommandConfig ​

cyModbusCreateCommand 的入参。返回对象字段相同，缺省项由工厂补齐。

字段类型入参缺省说明
descstring必填-描述
methodstring必填-指令标识，事件回调按它路由
typecyModbusOptionType必填-功能码
paramsIModbusCommandParams必填 start见下表地址、数量、写入值、心跳间隔
handleParams(val: number[]) => number[]可选原样拷贝send(cmd, { values }) 时转换写入值
handleParamsOn() => number[]可选() => [1]send(cmd, { action: "on" })
handleParamsOff() => number[]可选() => [0]send(cmd, { action: "off" })
handleResult(val: number[]) => number[]可选原样拷贝业务自行转换。成功事件里的 result 仍是原始 number[]

指令参数 params（IModbusCommandParams） ​

字段类型入参缺省说明
startnumber必填-起始地址
rangenumber可选1读操作的数量。写操作实际数量以写入数组长度为准
valuesnumber[] | null可选null配置中的写入值。send 传入 values 或 action 时会覆盖
durationnumber可选不写入该字段心跳间隔（毫秒），仅心跳指令需要

未传 values、也未传 action 时，写指令按 [0] 写 1 个点。values 为空数组时无法格式化。

发送选项 IModbusSendOptions ​

CyModbusService.send 的第二个参数。不修改原指令对象。

字段类型说明
action"on" | "off"线圈类。"on" 走 handleParamsOn，"off" 走 handleParamsOff
valuesnumber[]寄存器类。走 handleParams；未提供 handleParams 时原样拷贝

同时传入 action 和 values 时，values 后生效。

任务成功 IModbusTaskSuccessPayload ​

QUEUE_TASK_SUCCESS 的 payload。

字段类型说明
resultnumber[]send 原始返回值，不经过 handleResult
extraDataIModbusCommandConfig本次指令配置。换算：extraData.handleResult(result)

任务失败 IModbusTaskFailedPayload ​

QUEUE_TASK_FAILED 的 payload。

字段类型说明
errorunknown错误信息
extraDataIModbusCommandConfig指令配置。无法解析时可能缺省

连接状态对象 IModbusConnectionStatus ​

字段类型说明
val-1 | 0 | 1 | 2见 cyModbusConnectStatus
isConnectedboolean是否已连接

底层构造 ICySerialPort ​

字段类型默认说明
debugbooleanfalse是否打印调试日志
timeoutnumber800默认通信超时（毫秒）
onConnect(data: unknown) => void-连接成功
onFail(error: IModbusErrorInfo) => void-失败回调。connect / send 先回调再抛出；disconnect 清理失败仅回调

底层发送选项 ICySerialPortSendOptions ​

字段类型说明

发送帧 ICySerialPortSendDataFormat ​

CySerialPort.send 的第一参数，也是各 *Format 的返回值。

字段类型说明
slavenumber从机地址，一般 1～247

starting_addressnumber起始地址
quantity_of_xnumber线圈或寄存器个数

读参数 IReadDataFormat ​

读类 *Format 的入参。

字段类型说明
slavenumber从机地址
starting_addressnumber起始地址

写参数 IWriteDataFormat ​

写类 *Format 的入参。

字段类型说明
slavenumber从机地址

错误信息 IModbusErrorInfo ​

onFail 的入参。cyModbusError 实例字段与之对应，并带 name: "cyModbusError"。可用 error.toInfo() 转成该结构，用 cyModbusIsError 判断类型。

字段类型说明
codeTModbusErrorCode | string错误码
messagestring错误信息
timestampstringISO 时间戳
detailunknown原始错误或附加信息，可缺省

错误码 TModbusErrorCode ​

错误码说明
MODBUS_UNSUPPORTED当前环境不支持 Web Serial
MODBUS_PERMISSION_DENIED串口权限被拒绝
MODBUS_OPEN_FAILED打开串口失败
MODBUS_STREAM_UNAVAILABLE读写流不可用
MODBUS_READER_WRITER_FAILED创建 reader / writer 失败
MODBUS_CONNECT_FAILED连接失败
MODBUS_NOT_CONNECTED未连接就发送
MODBUS_SEND_FAILED发送或参数格式化失败
MODBUS_CLOSE_PORT_ERROR关闭串口失败
MODBUS_TIMEOUT_ERROR通信超时

setTimeout 传入非正数时，错误码为 MODBUS_INVALID_ARGUMENT（不在上面的联合类型里，仍通过 onFail 抛出）。
